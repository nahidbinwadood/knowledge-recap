# Knowledge Recap — 30-Day Software Engineering Rebuild

A structured 30-day roadmap to rebuild coding fluency, fundamentals, problem-solving ability, frontend engineering depth, backend understanding, architecture skills, and interview readiness.

> **You are the programmer. AI is your senior engineer/reviewer, not your replacement.**

## Quick Start

```powershell
pnpm install
pnpm run day:01
```

## Each Day Contains

| File | Purpose |
|------|---------|
| `README.md` | Day overview, topics, exercises, and instructions |
| `practice.ts` | Your implementations (run with `pnpm run day:XX`) |
| `notes.md` | What you learned, what confused you, key takeaways |
| `blog.md` | A small learning article for memory retention |

## Daily Workflow

1. **Learn** — Read the day's topics and understand the concepts.
2. **Practice** — Write code yourself. Struggle first. Debug yourself.
3. **Explain** — Write your understanding in `notes.md`.
4. **Write** — Publish a blog post in `blog.md`.
