# Day 1 — JavaScript Arrays and Objects

Your goal today is to rebuild comfort with everyday JavaScript operations—not to
memorize every array method.

## Start here

1. Install the small local toolchain once: `npm install`
2. Open [practice.ts](./practice.ts).
3. Pick one `TODO`, write pseudocode as a comment, then implement it yourself.
4. Uncomment that function's `console.log` line and run `npm run day:01`.
5. When you are finished, write what happened in [notes.md](./notes.md).

## Exercises

- [ ] `getActiveUsers` — `filter`
- [ ] `getAverageAge` — `reduce`
- [ ] `getOldestUser` — `reduce` or a loop
- [ ] `getUserNames` — `map`
- [ ] `groupUsersByRole` — `reduce`
- [ ] `countUsersByStatus` — `reduce`
- [ ] `removeDuplicates` — `Set`
- [ ] `sortProductsByPrice` — copying arrays and `sort`
- [ ] `getCartTotal` — `reduce`

## Rules for the session

- Spend the first 60–90 minutes solving and debugging without AI-generated code.
- Ask for a hint, a test case, or a review only after you have attempted it.
- Explain every solution in your own words in `notes.md`.
